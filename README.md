# 精酿酒吧空桶回收押金与批次追溯平台

面向精酿酒厂的全链路协同平台：酒桶从 **灌装入库 → 配送 → 酒吧开桶 → 打空回收 → 司机扫码 → 清洗检测 → 再灌装** 的完整生命周期追溯，以及围绕 **押金账期、异常协同、批次停售/召回** 的多角色（酒厂仓库 / 酒吧店长 / 司机 / 清洗厂 / 品控 / 财务 / 经销商）协作处理。

## 技术栈

- **前端**：React 18 + Vite + React Router（`web/`）
- **后端**：Go 1.19 + Gin + lib/pq（`server/`）
- **数据库**：PostgreSQL 15（`server/schema.sql`，服务启动时自动建表）

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 批次管理 | IPA/世涛/小麦/酸啤批次建档（灌装日期、最佳饮用期、酒精度），停售/恢复/召回 |
| 酒桶追溯 | 单桶全链路时间线：灌装、配送、签收、开桶、反馈、打空、回收扫码、清洗、押金流水 |
| 配送订单 | 酒厂→酒吧 / 酒厂→经销商 / 经销商→酒吧；支持**节日临时铺货**标记；记录司机与酒吧收货人 |
| 开桶反馈 | 出酒速度、气压、口味异常、客诉；同批次 ≥2 家酒吧严重反馈自动生成**批次投诉**异常 |
| 空桶回收 | 酒吧预约 → 司机接单 → 逐桶扫码（数量/外观/残液/封盖）→ 漏扫自动生成异常事件 |
| 清洗检测 | 清洗厂登记检测结果；合格获得**再灌装资格**并通知财务，不合格自动生成异常 |
| 押金财务 | 按酒吧/经销商账户 + 账期管理；送达挂账，按桶**释放/扣减**；逾期流水高亮 |
| 异常协同 | 延迟归还(超30天自动检测)/丢失/变形/批次投诉/漏扫/清洗不合格，六方在同一事件内处理并办结 |
| 批次召回 | 自动圈定范围：**已售卖/已开桶/未开桶/在库/在途/经销商库存**，通知酒吧/司机/经销商/财务 |
| 批次停售 | 通知已收货酒吧（禁止开桶，API 强制拦截）、待配送订单、经销商库存 |
| 通知中心 | 召回/停售/异常/押金/预约/订单六类通知，按用户/角色/酒吧定向投递 |

## 本地启动

### 方式一：一键启动（推荐）

```bash
./start.sh
```

脚本会：启动工作区自带的 PostgreSQL 实例（`.pgdata`，端口 5433）→ 编译 Go 后端 → 构建前端 → 在 **http://localhost:8080** 提供完整应用（API + 前端页面）。首次启动自动建表并写入演示数据。

### 方式二：分步启动

```bash
# 1. 数据库（任意 PostgreSQL 均可；以下为工作区自带实例）
/usr/lib/postgresql/15/bin/pg_ctl -D .pgdata -l /tmp/pg.log start
psql -h 127.0.0.1 -p 5433 -U postgres -c "CREATE DATABASE kegtrace"   # 首次

# 2. 后端（自动建表 + 种子数据）
cd server
go build -o ../kegtrace-server .
DATABASE_URL="host=127.0.0.1 port=5433 user=postgres dbname=kegtrace sslmode=disable" \
  WEB_DIST=../web/dist ../kegtrace-server        # http://localhost:8080

# 3. 前端开发模式（可选，热更新，端口 5173，代理 /api 到 8080）
cd web
npm install
npm run dev                                       # http://localhost:5173
```

环境变量：`DATABASE_URL`（默认 `host=127.0.0.1 port=5433 user=postgres dbname=kegtrace sslmode=disable`）、`ADDR`（默认 `:8080`）、`WEB_DIST`（默认 `../web/dist`）。

## 测试账号（密码均为 `123456`）

| 账号 | 角色 | 主要功能入口 |
| --- | --- | --- |
| `admin` | 管理员 | 全部功能 + 平台账号列表 |
| `warehouse` | 酒厂仓库 | 批次/酒桶入库/配送单/再灌装/基础数据 |
| `qc` | 品控 | 批次停售/恢复、发起召回、异常办结 |
| `finance` | 财务 | 押金账户流水、按桶释放/扣减 |

| `dist_hz` / `dist_sh` | 经销商（杭州/上海） | 经销商库存、向酒吧铺货（含节日临时铺货） |

种子数据包含：4 个批次（IPA/世涛/小麦/酸啤）、27 只各状态酒桶、2 城经销商、4 家酒吧（不同押金账期）、押金挂账流水、以及自动生成的**批次投诉**（酸啤被 2 家酒吧严重反馈）与**延迟归还**（KEG-IPA-010 超 30 天未还）异常事件。
